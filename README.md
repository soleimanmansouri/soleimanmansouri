### Hi, I'm Soleiman.

Not a programmer. A strategist who got tired of watching AI agents repeat the same mistakes.

I work at the intersection of AI systems and real-world operations — designing how agents should think, not writing the code that makes them run. After hundreds of debugging sessions across voice AI, automation pipelines, and enterprise systems, I noticed something: the same 19 root causes explain most failures. No one had documented them.

So I did.

[Debug Bank](https://github.com/soleimanmansouri/debug-bank) — A pattern-first debugging memory for AI coding agents. 19 patterns. 7-step protocol. One curl command. Used with Claude Code, Codex CLI, Gemini CLI, and Cursor.

Based on [Google's ReasoningBank research](https://arxiv.org/abs/2504.09762) (+8.3% WebArena, +4.6% SWE-Bench).

Built from the operator's chair, not the IDE.
