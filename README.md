## What I'm Building

**[CARA8](https://cara8.ai) — Dealership Operating System**
One platform replacing 6 enterprise vendors. Voice AI is just the front door — behind it:
- **50+ page dashboard:** CRM, leads, appointments, analytics, billing, KFZ-Schein OCR, 7-tier permissions
- **Voice pipeline:** 26 intent flows, MiniLM bypass classifier, trajectory learning
- **DMS bridge:** Playwright RPA on dealership VMs — automating legacy systems with no API
- **Background automation:** transcription sweep, DMS queue, vehicle sync, capacity sync, accounting (n8n + Odoo)
- **Multi-dealer:** VW, Skoda, Audi — same OS, different config per dealer

723 commits across 3 repos. 86% solo engineering output. Live in production.
